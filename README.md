# Railway Reservation Analyzer

This is my first semester Python project (PS No. 85) at Rungta International Skills University.

The program reads train booking data from a CSV file (bookings.csv) and does the following:
- shows the number of bookings for each train
- shows the revenue of each train (only Confirmed tickets)
- skips rows that have an invalid fare
- draws bar charts using Matplotlib

## How to run
1. Install the libraries: pip install pandas matplotlib
2. Keep railway_analyzer.py and bookings.csv in the same folder
3. Run: python railway_analyzer.py

## Files
- railway_analyzer.py - the Python program
- bookings.csv - sample booking data
